## Introduction
This responsive personal portfolio introduces Oluwafemi Ezekiel, highlights technical skills, demonstrates practical web applications, and includes an interactive academic planner and contact form. It was developed as a COS 106 laboratory project.

## Pages
- **Home (`index.html`):** Introduction, portrait, navigation, project links, and embedded portfolio walkthrough video.
- **About (`about.html`):** Education, career aspirations, skills, and an HTML skills table.
- **Projects (`projects.html`):** Three original applications with screenshots and links to run each app.
- **Academic Planner (`planner.html`):** Add and manage academic tasks with deadlines, priorities, search, status filters, and browser storage.
- **Contact (`contact.html`):** Validated demonstration contact form with submission confirmation and a return-home button.

## Featured projects
1. **GradePilot:** A five-point GPA calculator for courses, credit units and grades, with CSV export and local storage.
2. **SpendWise:** A personal income and expense tracker with transaction management, category breakdown, search/filter and CSV export.
3. **QuizForge:** A 15-question programming quiz with timed questions, feedback, score tracking, and a locally saved personal best.

## JavaScript functionality
- Responsive mobile menu and page interactions.
- Planner task management, status counts, filtering, deadline handling, and `localStorage`.
- Contact form validation (including numeric phone input) and a client-side success popup.
- GPA calculations, expense calculations, timed quiz questions, and CSV exports inside the mini-applications.

## Multimedia
The homepage includes a playable portfolio walkthrough video at `assets/videos/portfolio-walkthrough.mp4`.

No frameworks, database, or backend service are required. Planner and mini-app data stored with `localStorage` remain in the same browser profile. The contact form is a **demonstration** and does not transmit email.
